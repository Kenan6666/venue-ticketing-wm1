# Interactive Venue Ticketing System (WM1)

A front-end ticket selection website for a theatre venue. Users explore the venue map, inspect seats, add tickets to a cart, and keep their selection after a page refresh.

Built with HTML, CSS and JavaScript. 

## Features

- Theatre map generated from JavaScript data
- Seat inspection with details and price shown before adding to cart
- Seat states: available, inspected, in cart, unavailable
- Zoom and directional navigation controls with Reset / Center View
- Shopping cart with prices, total and ticket removal
- Duplicate seat prevention
- Cart and seat states saved in localStorage
- Responsive layout

## How to Run

1. Clone the repository or download the files.
2. Open `index.html` in a web browser.


## Project Structure

- `index.html` — page layout and controls
- `style.css` — styles and responsive layout
- `app.js` — venue data, seat generation, cart logic and localStorage
